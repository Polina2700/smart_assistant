# Project Proposal — SAP S/4HANA Public Cloud (FI/CO)
**Prepared for:** GreenEnergy Slovenia d.o.o.
**Prepared by:** NovaTech Consulting
**Date:** 2023-05-20
**Valid until:** 2023-06-20

---

## Executive Summary
NovaTech proposes SAP S/4HANA Public Cloud implementation (FI and CO modules) for GreenEnergy Slovenia. Total investment: **€89,000**. Go-live target: October 2023.

---

## Scope
- Financial Accounting (FI): GL, AP, AR, Asset Accounting
- Controlling (CO): Cost Centers, Internal Orders
- Grant/subsidy accounting (standard SAP functionality)
- 45 users (5 finance, 40 view-only/approvals)

## Not in Scope
- MM, PP, SD modules
- HR/Payroll
- Custom development (public cloud — standard only)

---

## Investment
| Item | Cost |
|------|------|
| Implementation (420 hours) | €63,000 |
| Training | €12,000 |
| Travel | €3,000 |
| Project management | €7,000 |
| Contingency (5%) | €4,000 |
| **Total** | **€89,000** |

SAP licenses: ~€1,800/month (45 users, Essential tier)

---

## Why Public Cloud for GreenEnergy
1. Small IT team — no SAP basis administration needed
2. Standard energy sector chart of accounts fits
3. Fast implementation (4 months vs 8 for on-premise)
4. Lower upfront cost
5. Automatic quarterly updates from SAP
