## SAP S/4HANA Public Cloud Pricing (2021 reference — MAY BE OUTDATED)

### User Types and Estimated Costs
Note: These are 2021 estimates. SAP pricing changes annually. Always verify with SAP directly before quoting.

| User Type | Estimated Monthly Cost (2021) | Description |
|-----------|------------------------------|-------------|
| Professional User | €213/user/month | Full access all modules |
| Limited User | €106/user/month | Limited transactions |
| Employee User | €27/user/month | Self-service only |

### Typical Annual License Costs by Company Size
- Small (up to 50 users): €60,000 - €120,000/year
- Medium (50-200 users): €120,000 - €400,000/year
- Large (200+ users): €400,000+/year

**WARNING: 2023 pricing is approximately 15-20% higher than these 2021 figures.**
See GreenEnergy proposal (2023) which uses €17.78/user/month for Essential tier — significantly different from above.
